# Changelog

All notable changes to this package are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the package follows [Semantic Versioning](https://semver.org/).

## 1.0.0 - 2026-10-29

### Added

Allows a Drupal site exposing nodes and taxonomies as JSON:API resources to be used as a content backend for a Laravel app. You can create listings of nodes and a search page with Livewire-powered pagination.
