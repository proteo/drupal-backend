## Drupal changes

- [ ] Implement `hook_ENTITY_TYPE_insert`, `_update` and `_delete` for every entity type the frontend renders: `file`, `media`, `node`, `taxonomy_term`. Edits to a type without a hook never clear the cache.
- [ ] Payload v2: `{"changes": [{"event": "<entity_type>.<insert|update|delete>", "entity_type", "bundle", "uuid", "nonce"}]}`; the frontend ignores the content, but the nonce prevents replay.
- [ ] Accumulate the changes of the request into that one `changes` list and send it once from `destruct()`, after the transaction commits.
- [ ] Settings `cache_webhook.url` and `cache_webhook.secret` (per Source, see above).
- [ ] Headers `X-Drupal-Timestamp` and `X-Drupal-Signature`, the HMAC-SHA256 of `{timestamp}.{body}` over the exact body bytes sent.
- [ ] The hook service is tagged `needs_destruction` and implements `DestructableInterface`.

Reference snippet:

```php
protected array $changes = [];

protected function scheduleFrontendFlush(EntityInterface $entity, string $operation): void {
  $this->changes[] = [
    'event' => $entity->getEntityTypeId() . '.' . $operation,
    'entity_type' => $entity->getEntityTypeId(),
    'bundle' => $entity->bundle(),
    'uuid' => $entity->uuid(),
    'nonce' => Crypt::randomBytesBase64(16),
  ];
}

public function destruct(): void {
  if (!$this->changes) {
    return;
  }
  $body = Json::encode(['changes' => $this->changes]);
  $this->changes = [];
  $secret = (string) Settings::get('cache_webhook.secret', FALSE);
  $url = Settings::get('cache_webhook.url', FALSE);
  if (!$secret || !$url) {
    return;
  }
  $timestamp = (string) $this->time->getCurrentTime();
  try {
    $this->httpClient->request('POST', $url, [
      // Must be the exact bytes that were signed.
      'body' => $body,
      'headers' => [
        'Content-Type' => 'application/json',
        'X-Drupal-Timestamp' => $timestamp,
        'X-Drupal-Signature' => hash_hmac('sha256', $timestamp . '.' . $body, $secret),
      ],
      'timeout' => 5,
    ]);
  }
  catch (\Throwable $e) {
    // Never break content editing because the frontend is unreachable.
    $this->logger->error('Frontend cache flush failed: @message', ['@message' => $e->getMessage()]);
  }
}
```
